# SILAPJU - Lapor Lampu Jalan Kota Bandung

Aplikasi pelaporan lampu jalan padam untuk Dinas Perhubungan Kota Bandung.
Dibuat sebagai Tes Akhir Praktikum Dasar Pemrograman Perangkat Bergerak Pekan 10.

## Fitur

- Formulir aduan berisi alamat, kecamatan, dan tanggal kejadian.
- Pemilihan kecamatan lewat ModalBottomSheet dengan drag handle.
- Pemilihan tanggal kejadian lewat showDatePicker.
- Dialog konfirmasi sebelum aduan dikirim.
- SnackBar berisi nomor tiket dan aksi BATALKAN.
- Riwayat aduan dengan ListView.builder dan tombol pembatalan.

## Menjalankan

```bash
flutter pub get
flutter run -d edge
```
